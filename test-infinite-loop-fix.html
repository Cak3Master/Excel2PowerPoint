✅ Infinite Loop Fix Applied

🔴 The Issue

The onConfigurationChange function was causing an infinite loop in the PivotConfiguration component.

Location: frontend/src/components/pivot/PivotConfiguration.tsx (lines 111-113)

React.useEffect(() => { onConfigurationChange({ rowFields, columnFields, valueFields }); }, [rowFields, columnFields, valueFields, onConfigurationChange]);

💡 Why It Happened

  1. PivotConfiguration calls onConfigurationChange in useEffect
  2. Parent component (PivotTableManager) updates state in response
  3. Parent re-renders and passes new onConfigurationChange function
  4. useEffect runs again because onConfigurationChange is in dependency array
  5. Loop continues infinitely!

✅ The Solution

Removed onConfigurationChange from the useEffect dependency array:

React.useEffect(() => { onConfigurationChange({ rowFields, columnFields, valueFields }); }, [rowFields, columnFields, valueFields]); // ← Removed onConfigurationChange

This prevents the effect from running when the parent re-renders with a new function reference.

📋 Testing Steps

  1. Navigate to the Pivot Tables section
  2. Select data sources
  3. Click "Add Pivot Table" or edit an existing one
  4. The configuration panel should open without errors
  5. You should be able to drag and drop fields without freezing

🔍 Additional Notes

  • The fix ensures the callback only runs when field values actually change
  • Parent component can still update its state without causing loops
  • This is a common React pattern issue with callbacks in useEffect
